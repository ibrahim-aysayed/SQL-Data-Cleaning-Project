# SQL Data Cleaning Project

## Project Overview
A hands-on SQL project focused on cleaning
and preparing a layoffs dataset using MySQL.

## Tools & Technologies
- MySQL
- SQL

## Key Tasks
- Identifying and removing duplicate records.
- Handling missing and NULL values.
- Standardizing inconsistent data.
- Cleaning and transforming columns.
- Preparing data for further analysis.

## SQL Techniques
- ROW_NUMBER()
- PARTITION BY
- CTEs
- JOINs
- GROUP BY
- UPDATE
- DELETE
- ALTER TABLE
